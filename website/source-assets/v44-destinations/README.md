# Owner-update destination photography — 12 November 2026

These are real wildlife photographs of the named destinations. Neither depicts
or endorses a bookable hotel, camp or supplier. Sources, authors, licence links,
verification date and source SHA-256 hashes are recorded in `credits.json`.

- Maasai Mara: **flowcomm**, “Landscape, Masai Mara, Kenya”, CC BY 2.0.
- Bwindi, Uganda: **Charles J. Sharp**, “Mountain gorilla (Gorilla beringei beringei)
  female Bwindi Uganda”, CC BY-SA 4.0. Resized/cropped/encoded versions of this
  photograph remain available under the same CC BY-SA 4.0 licence.

`node scripts/prepare-owner-photographs.mjs` generates 640/1280/1920 px AVIF and
WebP copies with a 3:2 crop, never enlarging a source. Published credits on the
destination cards and pages name the photographer, link the source and licence,
and state that the photo is cropped. The original files are retained here.

The About-page wilderness image is the existing licensed **Sweder Breet**
Amboseli photograph (`v24-photography/africa-v24.jpg`, Unsplash License). It is
captioned as Amboseli, Kenya; it is not presented as Maasai Mara or as a leopard.
The existing leopard in the homepage band is preserved as an illustration.

The first homepage destination window now uses the existing licensed real Zanzibar photograph, `zanzibar-v24` (Jack Balke / Unsplash License), in a centre crop. The Seychelles and Maldives windows retain their existing V39 illustrative portraits. The six homepage destinations and the listing now follow the same priority order; East Africa and Europe follow as wider collections.
